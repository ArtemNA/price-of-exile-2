# Сценарії для перевірки в справжній PoE2

Усе нижче вже працює на фейковій грі (знімки в [screenshots](screenshots/README.md)). Тут — те, що
може повестися інакше лише в справжньому клієнті. Порядок — від головного до рідкісного; кожен пункт
займає хвилину-дві. Що не так — скріншот і (де сказано) текст предмета, решту я знайду в лозі.

## Підготовка

- Збірка: інсталятор з артефакту останнього запуску [Release](https://github.com/ArtemNA/price-of-exile-2/actions/workflows/release.yml)
  (`price-of-exile-2-windows` → `Price.of.Exile.2_<версія>_x64-setup.exe`) або `npm run dev` з репо.
- Гра у вікні або «windowed fullscreen», ліга — та, що в налаштуваннях (за замовчуванням Forbidden Rites).
- Price of Exile (PoE1) і Exiled Exchange 2 на час перевірки закрити: у них ті самі хоткеї.
- Лог: Settings → Log (або `%LOCALAPPDATA%\com.artemna.price-of-exile-2\logs`).
- **Текст предмета** — навести курсор у грі й натиснути Ctrl+Alt+C, потім вставити в чат зі мною.

## 1. Копіювання й попап (головне)

| # | Що зробити | Що має бути |
|---|---|---|
| 1.1 | Settings → Hotkeys, блок «Item copy keys» | «Ctrl + Alt + C», джерело — конфіг гри (або твоя клавіша, якщо в грі «show advanced item descriptions» не Alt) |
| 1.2 | Рідкісний предмет, Ctrl+D | Попап біля панелі інвентаря за мить, гра не втрачає фокус; у фільтрах є тіри (T1…), отже, текст скопійовано з розширеним описом |
| 1.3 | Той самий предмет двічі поспіль, Ctrl+D | Обидва рази попап (той самий предмет у буфері не заважає) |
| 1.4 | Esc, клік поза попапом | Попап закривається, гра знову отримує клавіатуру |
| 1.5 | Після Ctrl+D відкрий у грі меню / чат | Alt не «залип»: меню гри не відкривається саме, Alt+Tab працює як завжди |
| 1.6 | Якщо в тебе є розкладка з AltGr (польська, німецька…) — Ctrl+D на ній | Попап з’являється. Якщо ні — скажи, яка розкладка |
| 1.7 | Предмет у сховищі (відкрита вкладка), Ctrl+D | Попап з того боку, де панель сховища |

## 2. Price check

| # | Що зробити | Що має бути |
|---|---|---|
| 2.1 | Рідкісна зброя / броня / біжутерія → Search | Лістинги, колонки «≈ ex» і «≈ c», курс «1 div = N ex · M c» у заголовку |
| 2.2 | Унікальний предмет | Пошук іде одразу; ціна poe.ninja з трендом |
| 2.3 | Неідентифікований унікальний предмет | Сам підбирає унікальний; якщо на базі їх кілька — «Which one?». **Надішли текст**, якщо трапиться база з кількома |
| 2.4 | Гем (некрамований / Uncut Skill Gem / Uncut Spirit Gem) | Рівень гема в чипах, пошук |
| 2.5 | Предмет з рунами в гніздах | Група «Runes», чип «Sockets ≥ N» |
| 2.6 | Предмет з desecrated / unrevealed модами | Група «Desecrated», рядок «Unrevealed …» |
| 2.7 | Fractured мод | Перемикач «Fractured» біля мода |
| 2.8 | Зіпсований предмет | Corrupted у шапці, «Corrupted» вибрано |
| 2.9 | Свій предмет на продаж (якщо вказаний Account name) | Свої лістинги підсвічено |
| 2.10 | Багато пошуків поспіль (десяток за хвилину) | Лічильник «Search N/M» унизу; при ліміті — «retry in N s», а не порожнє вікно чи помилка |

## 3. Валюта й bulk

|---|---|---|
| 3.1 | Exalted Orb / Chaos Orb / Divine Orb, Ctrl+D | Вкладка Bulk відкривається сама, пропозиції divine / exalted / chaos |

## 4. Item check (Alt+D) і посилання

| # | Що зробити | Що має бути |
|---|---|---|
| 4.1 | Зброя, Alt+D | DPS: фізичний, стихійний, хаосом, Total; для арбалета — Reload time. **Надішли текст**, якщо зброя з уроном хаосом у ru-клієнті |
| 4.2 | Wiki / PoE2DB / Craft of Exile | Відкриваються правильні сторінки; Craft of Exile лише для предметів під крафт — скажи, чи CoE підхопив предмет |
| 4.3 | Find in Stash | Назва вводиться в пошук відкритого сховища |
| 4.4 | Скрижаль (Precursor Tablet), Alt+D | Item check, без помилки. **Надішли текст** — у тестах лише стара назва бази |

## 5. Map check (вейстоуни)

| # | Що зробити | Що має бути |
|---|---|---|
| 5.1 | Вейстоун з модами, Alt+D | Тір, числа (Pack size, Magic / Rare monsters, Drop chance…), моди з позначками |
| 5.2 | Вейстоун з гібридним модом (два рядки) | Обидва рядки розпізнано. Якщо один у «Unrecognised» — **надішли текст** |
| 5.3 | Ctrl+D на вейстоуні | Price check з чипом «Waystone tier» |

## 6. Чат і сховище

| # | Що зробити | Що має бути |
|---|---|---|
| 6.1 | F5 | `/hideout` |
| 6.2 | F9 | `/exit` — повертає на екран вибору персонажа. Якщо в PoE2 такої команди немає — скажи; глянь `/help` |
| 6.3 | Після угоди: `@last ty`, `/invite @last`, `/tradewith @last`, `/hideout @last` | Команди спрацьовують; повідомлення гравцю йде |
| 6.4 | Alt+F у сховищі → пресет | Текст вводиться в пошук сховища, предмети підсвічуються |
| 6.5 | Після будь-якої команди | Твій буфер обміну повернувся (те, що ти копіював до того) |

## 7. Вбудований браузер

| # | Що зробити | Що має бути |

## 8. Російський клієнт (якщо граєш або можеш перемкнути)

| # | Що зробити | Що має бути |
|---|---|---|
| 8.1 | Settings → General → Game language: Русский, будь-який предмет | Price check, пошук на ru.pathofexile.com. **Надішли текст** будь-якого рідкісного предмета — справжнього ru-тексту в тестах немає |
| 8.2 | Зброя з уроном хаосом | Chaos DPS є (рядок «Урон хаосом: » — здогадка) |
| 8.3 | Сумарні моди (Σ) | Як їх пише ru-сайт — з «+» чи без; у нас зараз без |

## 9. Швидкість

Попап у еталоні (PoE1) з’являвся за 64–65 мс від натискання. На фейковій грі в нас 75 мс, з них
48 мс — очікування першої перевірки буфера (F-31). Для заміру в справжній грі: відкрий гру, наведи
курсор на рідкісний предмет в інвентарі, скажи мені «міряй» і хвилину не чіпай мишу й клавіатуру.
